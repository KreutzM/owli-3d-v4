# Owli reference image

Place the original supplied 360° design sheet at:

```text
references/Owli_Character-Sheet.png
```

This repository's initial scaffold contains **only this instruction file** because the binary chat attachment could not be transmitted into GitHub as part of the repository-creation operation.

Important: the repository is **public**. Only upload image assets that you intend to publish. The full-resolution sheet is the art authority; do not replace it with a generated reinterpretation. Rendered panels should be compared at 0°, 45°, 90°, 135°, 180°, 225°, 270° and 315°.

Use `git add references/Owli_Character-Sheet.png` after saving the original file. Image references do not belong in `build/`.
